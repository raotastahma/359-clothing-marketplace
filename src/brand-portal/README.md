# Brand portal

The primary React, TypeScript and Vite application for brand accounts. See the repository root README for the fictional portal-to-storefront demo. Run `npm ci`, set `VITE_API_URL` to your local backend, then use `npm run dev` or `npm run build` and `npm run preview`. The portal supports catalog, variant, order and financial workflows through authenticated backend routes. Existing product UI copy includes Russian.
